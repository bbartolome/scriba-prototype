- **D1. Extend `DiffView` in place.** `DiffView` (`apps/web/src/app/shell/diff-view.ts`) gains an `editable` input (default `false`) and a `contentChange` output. No new component and no new export. 3. **The editable line model (D9, option (e)).** In `diff-view.ts`:
   - a. **Documents.** With `editable` true, the proposed document is the `proposed` string itself (not `toText(proposed)`), with `documentExtensions(proposed)` in place of `EditorState.lineSeparator.of('\n')`. `EditorState.create` splits a string document on the facet (`@codemirror/state` lines 2760 and 2761), so a CRLF-dominant text has no CR in its line text.    - b. **The override.** A module function `crlfOverride(a: string, b: string): readonly Change[]`. `a` is the base document as a string and `b` the proposed document as a string, both joined with `\n` by the merge package (`Chunk.build` calls `toString`, `@codemirror/merge` line 650; the incremental update calls `sliceString`, line 756, whose default separator is `\n`, `@codemirror/state` lines 179 and 271). Under the LF split the base's CRs are characters of its lines, so `a` holds the base bytes as they are; `b` has lost its CRs. The function:
     1. `const restored = b.replace(/\n/g, '\r\n');` (the CRLF-restored proposed text of the Navigator's decision).
     2. `diff(a, restored, { scanLimit: 500 })`, the package's own `diff` (exported, line 1773). The config has no `override`, so the call does not recurse (lines 491 to 493). `{ scanLimit: 500 }` is the package default (line 770).

     4. Widen a line-break-only change: if `a.slice(fromA, toA).replace(/\r/g, '')` equals `b.slice(fromB, toB).replace(/\r/g, '')`, the change differs only in a CR. Set `fromA` and `fromB` to the start of their line (`s.lastIndexOf('\n', p - 1) + 1`) and `toA` and `toB` to just after the next `\n` from that start (or the string's end). Without this rule an LF-to-CRLF-only change gives empty chunks (`[6,6,6,6]`, `[11,11,11,11]`, probes F23 and F25 f0); with it, one chunk `[0,11,0,11]` (F25 g1).
