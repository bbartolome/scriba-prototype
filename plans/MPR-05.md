### 3a. The resolver's algorithm (step 4)

`resolve({projectId?})`:
1. `choice = (projectId === undefined ? undefined : this.projectChoice(projectId)) ?? this.registry.appDefault()`. If `choice` is null, throw `PROVIDER_NOT_CONFIGURED` ("No app default is set.").
2. `provider = this.registry.get(choice.providerId)`. If undefined, throw `PROVIDER_NOT_CONFIGURED` (409) with the message "The app default names a provider that does not exist." (open point 5, closed).
3. `key = provider.keyRef === undefined ? undefined : this.secrets.get(provider.keyRef)`.
4. If `choice.model !== ''`, the result is `{model: choice.model, source: 'app'}`. An override reaching this step is MPR-12's case (open point 6).
5. Else, if `provider.model !== ''`, the result is `{model: provider.model, source: 'app'}` (open point 1, closed).
6. Else `ids = await listModels({config: provider, key, model: ''})`. If `ids` is empty, throw `PROVIDER_NOT_CONFIGURED` ("The provider lists no models.") with `details: {hint}` when `isOllamaProvider(provider)` (D13). Else the result is `{model: ids[0], source: 'auto'}`, where `ids[0]` is the first id in the provider's own order (open point 3, closed).
7. Return `{config: provider, key, model, contextSize: provider.contextSize, source}`. Write nothing.

`modelList(providerId)`: `provider = registry.get(providerId)`; if undefined, throw `PROVIDER_NOT_FOUND`. `ids = await listModels({config: provider, key, model: ''})`. Return `[...ids].sort()`, for display only.
