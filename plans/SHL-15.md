# SHL-15 plan — editor layout: split view with live preview, phone toggle, tablet touch checks

Batch: [SHL-15] (Frontend shell, phase:editor, M3); batch of one. Revision 1, status draft (planner, 2026-11-16). Base: `main` at `08c1202`. SHL-11, SHL-13 and SHL-14 are merged (`git merge-base --is-ancestor` for b36fb90, 7cc7601 and 801a967 holds), so "parallel with SHL-14" means SHL-14's code is already on `main`.

## 1. Decisions this plan follows

- **D1. Split view on tablet and desktop; edit/preview toggle on phones.** Source: `units/SHL-15-editor-layout-touch.md` line 18.
- **D2. No feature depends on a hardware-only shortcut.** The Save button covers Cmd/Ctrl-S. Source: unit line 19.
- **D3. A layout switch inside the page, not a route.** Long-form editing on phones is a layout switch inside a phone-class page (`units/SHL-05-breakpoint-gate-nav.md` line 22). The page switches layout on the device-class signal (`modules/shell.md` line 70). The signal is `DeviceClassService.deviceClass` (`apps/web/src/app/shell/device-class.ts` lines 57 and 71). No pixel widths are used (`modules/shell.md` line 108).
- **D4. The editor stays rendered while its text is unsaved.** The toggle hides a pane with the `hidden` attribute. It never removes the editor with `@if`. Sources: `plans/SHL-14.md` section 5, rule (a) (line 190) and open point 6 (line 205); `units/SHL-05-breakpoint-gate-nav.md` line 20 ("An open view is not torn down", which protects unsaved editor text).
- **D5. SHL-15 wraps the editor and does not change it.** `MarkdownEditor` keeps its inputs (`reference`, `readOnly`, `saveMode`) and outputs. No line of `markdown-editor.ts` or `markdown-editor.spec.ts` changes. Sources: `plans/SHL-13.md` line 159 ("Adds the split view and the toggle around this component; does not change its inputs"); `plans/SHL-14.md` section 5, rules (b) to (d) (line 190); section 8 (lines 253 to 256).
- **D6. The preview is SHL-11's and is unchanged.** It hides a leading front-matter block (`units/SHL-11-markdown-preview.md` line 19; Navigator decision of 2026-11-14 on the front-matter rule, `plans/DECISIONS.md` line 3462, whose effects line 3466 names SHL-15). Raw HTML shows as text (Navigator decision of 2026-11-14 on raw HTML, `plans/DECISIONS.md` line 3425). SHL-15 adds no preview rule.
- **D7. Vitest edits go through the editor view, not through typing.** Use `EditorView.findFromDOM` and `dispatch`. Source: Navigator decision of 2026-11-14 on SHL-13 open point 7 (`plans/DECISIONS.md` line 3630), the same seam as `apps/web/src/app/shell/markdown-editor.spec.ts` lines 162 and 327.
- **D8. The layout passes no save mode.** The editor has one value, `'direct'` (`apps/web/src/app/shell/markdown-editor.ts` line 114; Navigator decision, `plans/DECISIONS.md` line 3629; `plans/SHL-14.md` open point 2 at line 201).
- **D9. Line separators and the BOM are the editor's.** The layout touches neither. Source: Navigator decision on SHL-13 open point 1, the bare-CR limit (`plans/DECISIONS.md` line 3627).
- **D10. Dark theme is checked by SHL-15.** Owner named by `plans/SHL-13.md` line 179 (open point 10). Covered by test X2.
- **D11. Test seams.** Unit tests: Angular's Vitest runner with the Shell's fakes (`modules/shell.md` line 92; `FakeApiClient` at `apps/web/src/app/shell/testing/test-doubles.ts` line 43). Breakpoints are driven by `stubMatchMedia` (`apps/web/src/app/shell/testing/match-media.ts` line 67; `modules/shell.md` line 93). System test: Platform's Playwright e2e on the build the API serves on port 8080 (`modules/shell.md` line 94; `e2e/playwright.config.ts` line 20).
- **D12. Blockers.** `blocked_by` is the source of truth (`units/README.md` line 64). SHL-15's `blocked_by` names SHL-11 and SHL-13 (unit line 7). `modules/shell.md` line 32 says "needs 11" only. The unit is followed, because the layout wraps the SHL-13 component.
- **D13. No new route, package or contract.** The route table is fixed (`modules/shell.md` lines 52 to 68). No package is added. `/shell` publishes no contract slice (`modules/shell.md` line 5). Open point 1 can change the route part only with a Navigator decision.
