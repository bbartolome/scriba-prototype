### 1c. Choices of this plan

- **D1 Template file and path.** `apps/api/assets/compile-export/typst-template.typst` (new). `apps/api/src/modules/compile-export/builtin-assets.ts` gets `BUILTIN_TYPST_TEMPLATE`, resolved with the same `resolve(__dirname, '..', '..', '..', 'assets', 'compile-export', ...)` form as `BUILTIN_REFERENCE_DOCX`. The path works from `src/` (tests, dev) and from `dist/` (image), as CEX-11 D1 states.
- **D2 Template content.** A full Pandoc template, because `--template` takes a whole template (the CEX-11 pattern). Pandoc 3.13's default Typst template calls a partial at its line 40 (`$template.typst()$`, the `$else$` branch of `$if(template)$`), and the partial is the data file `templates/template.typst` (F16). The built file is one self-contained file, derived with two changes only (step 3), the simplest template that meets the unit:
  - (a) the default template (`pandoc --print-default-template=typst`), with line 40 replaced by the text of the partial (`pandoc --print-default-data-file templates/template.typst`);
  - (b) one show rule is inserted before the `$body$` line: `#show heading.where(level: 1): it => { pagebreak(weak: true); it }`, which gives the page break per chapter that the unit's spike names. It is placed after the `$if(toc)$` block, so the TOC's own title is not affected.
  Pandoc's `$...$` placeholders are kept, and the partial's defaults stay: paper `us-letter`, margin `1.25in`, font size `11pt` (F16). The `$if(smart)$ ... $endif$` block stays: with the runner's `--from=markdown` Pandoc sets `smart`, so the block writes nothing and Typst's smart quotes stay on (F27, A1). Reason: one file, and the spike checks its look; any other layout change is made only if a spike row fails (D11). The text font is Typst's default, Libertinus Serif (bundled; F15, F19). The unit asks for a built-in template, not a DOCX-like layout, so the DOCX's font and spacing are not copied. (Reviser: the planner's margin, font-size and smart-block edits are dropped as not needed by the unit; simplest option.)

- **D10 Checklist.** Written in the ADR before any render (step 11a). No row is changed after the first render, because the rows decide the outcome (D11).
  - S1 Header and engine: the PDF of the stress fixture starts with `%PDF-` at byte 0, and its Creator is Typst 0.15.1.
  - S2 Footnotes: each note's text is on the page of its marker, and the numbers run on across the book. The stress file has three notes, one of them inside a block quote.
  - S3 Block quotes: the quote is one indented block, and its two paragraphs stay inside it.
  - S4 Smart quotes: curly double and single quotes. No straight `"` or `'` appears in the rendered text.
  - S5 Dashes: `--` renders as an en dash and `---` as an em dash.
  - S6 Accented Latin (é, ü, ç, ñ) renders with the right glyphs.
  - S7 Greek and Cyrillic render with glyphs, with no empty boxes.
  - S8 CJK: the stress file has one CJK line. Pass: the line renders with glyphs, or its only defect is a missing font (`typst fonts` lists no CJK family in the image, F15) and the ADR's Consequences name a CJK font as a follow-up. A missing font is a property of the image, not of Typst, and the TeX Live derived image would need the same font.
  - S9 Long headings: a level-1 heading of more than two lines wraps inside the margins and appears whole in the TOC.
  - S10 TOC: with `--toc`, every chapter appears in order with its page number.
  - S11 Chapter breaks: each level-1 heading starts a new page, and no blank page appears.
  - S12 Image: `drafts/image.svg` renders no wider than the text block, with its caption.
  - S13 Sample: the nonfiction sample exports its four chapters in effective order, with the author and the dedication. Pandoc and Typst write no warning on stderr, or each warning is recorded.
- **D11 Decision rule.** From the unit's wording (line 16): the spike "compare[s] against a written checklist", and the outcome is one of two. So the checklist of D10 is the rule. The ADR says "Keep Typst." when every row S1 to S13 passes with the final built-in template of this PR. A row that fails may be fixed in the built-in template within this PR (the template is this unit's deliverable) and checked again; the ADR records the fix. If any row still fails, the ADR says "Recommend the TeX Live derived image (`FROM bbartolome/scriba`) as follow-up work, not in v1." For each row, the ADR gives the result, the page number and the PNG page that shows it. The rows are fixed before the render (D10), so the decision follows from the results (open point 6).
- **D12 Spike method.** Each input goes through the real export route (a throwaway spec, deleted before the commit; step 11c). The visual check compiles the Typst source that Pandoc writes for the same input and the same template, with `typst compile --format png --ppi` (F15), because that source produces the same pages as the PDF (A3). The PDF itself is checked for S1 and its text, not by eye.
- **D13 Test names and seams.** C1 is a Vitest test under `itPdf`. E1 is a Vitest test under `it`. C2 is a shell check on the ADR file, because the ADR is a document and the spike review is manual (module line 62). The C2 check runs on the branch and again on main after the merge.
